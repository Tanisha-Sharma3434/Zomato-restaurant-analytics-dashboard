# Zomato Restaurant Analytics Dashboard

## 📊 Project Overview

This project presents an interactive restaurant analytics dashboard created using Microsoft Excel and a sample Zomato-style restaurant dataset.

The dashboard helps explore restaurant ratings, monthly orders, revenue, online ordering, home delivery, customer votes, and delivery time.

## 🎯 Project Objectives

* Analyze average restaurant ratings by cuisine and city.
* Compare monthly orders across cuisines.
* Explore monthly revenue across cities.
* Review online ordering and home delivery trends.
* Present key metrics using KPI cards.
* Enable interactive filtering using slicers.

## 🛠️ Tools & Skills

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* KPI Cards
* Slicers
* Data Analysis and Data Visualization
